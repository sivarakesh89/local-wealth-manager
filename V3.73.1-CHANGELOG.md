# FinMate v3.73.1 — Essentials month selector fix

## Bug fixed
The Essentials month selector validated the selected value using an incorrectly escaped regular expression. Valid `YYYY-MM` values were rejected, so the Financial Profile displayed the current month even after a different month was chosen.

## Change
- Corrected the month validation pattern to accept valid `YYYY-MM` values.
- Kept the existing Essentials month change handler and its session-local selection behavior.
- Left Dashboard and Transactions month selectors independent.
- No transaction, vault, or media data is modified.
