# FinMate v3.25.0

## Mobile Transactions layout
- Increased the Category column and added an explicit mobile `<colgroup>` so the five transaction columns keep a predictable balanced width.
- Category now displays the icon above the category name.
- Category names stay on a single readable line with ellipsis for very long names; short names such as `Blr` remain `Blr` instead of wrapping one character per line.
- Description retains substantial width.
- Type and Actions are compact while Amount remains comfortably readable.
- Service-worker cache version bumped to v3.25 to ensure the new CSS/markup is picked up.
