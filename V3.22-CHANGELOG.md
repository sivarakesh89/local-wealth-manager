# FinMate v3.22.0

- Mobile Transactions uses compact **I** and **E** indicators instead of the full Income/Expense text, helping the category column remain visually prominent. Desktop retains the full transaction type.
- Added category-specific emoji badges for a broader set of common category names.
- For custom/unrecognized category names, a colored badge is generated automatically from the category's first character. This works for categories added later as well, without needing an icon file or manual mapping.
- Existing transaction editing, deletion, filters, amount/date layout, and laptop presentation remain intact.
