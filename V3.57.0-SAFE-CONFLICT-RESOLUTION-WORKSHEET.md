# FinMate v3.57.0 — Safe Conflict Resolution Worksheet

## Purpose
Adds an optional, separate JSON resolution worksheet after the read-only three-way conflict review. It carries the record classification and allowed review decisions, with every decision initially `UNRESOLVED`.

## Safety boundaries
- Creating the worksheet does not alter local records, Google Drive vault, shared baseline, media, or pending journal.
- No choice is automatically applied. The worksheet is not an importable vault and is not an apply/merge engine.
- The worksheet can become stale. Run a fresh three-way review before using it to guide any future resolution.
- Treat exported IDs and labels as private financial metadata.
- Deletion candidates are not proof of intent. Confirm them manually.

## Staging checklist
1. Deploy to staging and confirm About shows `3.57.0`. Keep v3.56.0 and backups unchanged.
2. Run Three-way conflict review with disposable staging records.
3. Export the review report and choose to create the separate resolution worksheet.
4. Inspect `FinMate-Conflict-Resolution-Worksheet.json`; each detail must start with `decision: UNRESOLVED` and list allowed decisions.
5. Edit a worksheet decision locally and confirm no FinMate or Drive data changes.
6. Confirm worksheet creation leaves local records, Drive vault, baseline, media, and pending count unchanged.
7. Re-run review and confirm fresh report reflects any changes made outside the review.
8. Test no-difference cases and deletion-versus-edit conflicts.

This release provides the reviewed decision-planning stage only. Applying choices to vault data is intentionally deferred until the worksheet format and recovery/rollback safeguards have been validated. Source syntax and ZIP integrity checks do not replace live Google Drive staging tests.
