# FinMate v3.52.0 — Conflict Resolution Worksheet

## Purpose
Adds an optional JSON worksheet after the read-only Drive comparison. The worksheet lists differing records, labels each decision as UNRESOLVED, and lists the review options. It is a human review artifact only.

## Safety guarantees
- Creating/exporting the worksheet does not write to Google Drive or modify local FinMate records.
- No worksheet decision is automatically applied.
- The worksheet may contain private financial record details. Store it securely.
- The worksheet can become stale; always re-run Compare with Drive before any future resolution.
- This release does not implement merge, baseline publication, or record-level sync.

## Staging test
1. Keep v3.51.0 and recovery backups unchanged. Deploy to a staging copy / separate browser profile.
2. Confirm About shows 3.52.0.
3. Run Compare with Drive and choose to create the conflict-resolution worksheet.
4. Open the JSON locally; confirm each item has a record ID, status, `decision: UNRESOLVED`, and allowed decision list.
5. Confirm local records, Drive vault, media, and pending journal count remain unchanged.
6. Confirm Retrieve remains blocked while local changes are pending.

This build has source-level checks only; test against staging Google Drive before normal use.
