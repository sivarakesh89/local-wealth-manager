# FinMate v3.46.2 — Media reference display fix

## Fix
- Gold-jewellery list UI now recognizes mediaRef-backed photos and invoices created by split-media recovery.
- Items with a photo stored separately show a PHOTO affordance rather than the empty-photo glyph.
- Items with a separately stored invoice show the View invoice / Open invoice PDF button instead of No invoice.
- Existing media shard format, IndexedDB stores, and attachment references are unchanged.
- Service-worker cache name updated to force the new app files to load.

## Important
This fixes the list UI that previously checked only inline `.data`. It does not prove that every stored attachment can be decrypted or displayed in the user's browser. If clicking PHOTO or View invoice still fails, record the exact alert text; do not re-import the core vault or clear site data.
