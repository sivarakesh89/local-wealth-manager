# FinMate v3.50.0 — Read-only Drive comparison

## What changed
- Adds **Compare with Drive** to the Google Drive sync panel.
- Reads and decrypts the current Drive vault, then compares record IDs and content across the supported collections.
- Reports local-only records, Drive-only records, and same-ID records whose content differs.
- The comparison is read-only: it does not upload, retrieve, merge, delete, or modify vault records.
- Existing pending-change journal and upload/retrieve safeguards remain in place.

## Important limitation
This first comparison phase does not yet establish a common per-record baseline or determine which side is newer. A difference is not automatically a conflict, and record-level merge/resolution is not enabled. Keep using the existing explicit Upload/Retrieve workflow. Do not upload from both devices when both have independent changes.

## Safe staging test
1. Keep v3.49.2 and all recovery files unchanged. Deploy v3.50.0 to a staging copy/browser profile first.
2. Unlock FinMate and open Settings → Google Drive.
3. Click **Compare with Drive**. Confirm it reports counts and makes no data changes.
4. Add a harmless test transaction on one staging device, upload it, then compare from the other staging device.
5. On the second device, make a separate harmless test transaction without uploading; compare again. Confirm local-only / Drive-only differences are reported as a preview.
6. Confirm the pending-change count remains intact and the existing retrieve guard still blocks retrieval while local changes are pending.
7. Verify photos/invoices still open.

Do not use the only production vault as a test device. The comparison has not been live-tested against your Google Drive account; it has only been source-checked.
