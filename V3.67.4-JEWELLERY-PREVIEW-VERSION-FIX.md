# FinMate v3.67.4 — About version and jewellery upload previews

- Bumped the runtime app version, IndexedDB app key, HTML asset query strings, and service-worker cache name to v3.67.4.
- Forces a new shell cache generation and uses the versioned app.js URL so the old About label should not persist when this release's index.html is deployed too.
- Added Coins to jewellery type choices.
- New jewellery defaults: 22K (91.6%) purity and stone weight 0 grams; existing edited entries retain their saved values.
- Selecting a photo or invoice now immediately shows a thumbnail or PDF/file indicator and the selected filename before saving.

Deployment: upload the complete ZIP contents, including index.html, app.js, app.css, sw.js and manifest.webmanifest, to the same GitHub Pages publishing root. Do not clear site data or IndexedDB.
