# FinMate v3.23.0

## Mobile Transactions category visibility
- Increased the mobile Category column width using the space freed by the compact I/E Type column.
- Category icon and editable category name are now visible together on mobile.
- Kept Amount/Date and Edit/Delete Actions visible.
- Added compact truncation for unusually long category names without removing the category text.

## Other behavior
- Desktop/laptop Transactions layout is unchanged.
- Existing filters, sorting, tags, and transaction editing/deletion are preserved.
