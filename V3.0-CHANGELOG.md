# FinMate v3.0.0

## Fixes
- PDF recovery now always reports a result and catches failures instead of silently doing nothing.
- PDF transaction parser expanded for common date/amount layouts and saved PDF text recovery.
- Fixed `Maximum call stack size exceeded` on large imports by using chunked base64 encoding for encrypted vault payloads.
- Import save now preserves exact source strings for imported numeric fields while keeping numeric values for calculations.
- Asset type inference now correctly recognizes stocks, mutual funds, bonds, ETFs, gold, silver, crypto, FD, PPF, EPF, NPS, real estate and vehicles from the Name/Investment field.
- Numeric display precision increased so imported decimal values are not rounded unnecessarily.
- Retrieve from Drive now uses the secure OAuth backend automatically on a new browser when no local refresh token is available, avoiding the GIS popup path that was producing `popup_closed`.
- Secure OAuth callback can automatically continue with the requested Drive retrieval after authorization.
- Mobile navigation drawer has a dedicated scroll area with a visible scrollbar/gutter.
