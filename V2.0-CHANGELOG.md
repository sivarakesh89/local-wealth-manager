# FinMate v2.2.0

- Replaced generated/temporary icon assets with the user's supplied FinMate icon image, resized into the full PWA icon set.
- Increased FinMate branding size in the desktop sidebar and mobile/main header.
- Added cache-busting icon URLs and bumped service-worker cache to v2.2.
- Added Settings → About FinMate with application version and architecture details.
- Hardened Google Drive Connect flow: Google Identity Services is loaded with deterministic script ordering; token errors, popup-blocking, popup-close, missing library and Drive API failures now show actionable messages.
- Google token request uses valid GIS prompt values (`consent` / `none`).
- Improved automatic FinMate Drive folder creation and diagnostics.
- Improved Stock Price Proxy parsing to accept a URL prefix ending in `url=` and proxies with query parameters such as `?key=...&url=`.
- Added PROXY-SETUP.md with the current practical CORSPROXY setup format.
- Existing local IndexedDB vault/database name remains unchanged; branding/version changes do not intentionally clear local financial data.
