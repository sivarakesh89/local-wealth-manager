# FinMate v3.38.0

## Jewellery
- Added jewellery type **Pendants**.
- Added Purchased rate per gram, Jewel amount, Stone amount, Gross amount, and Discount fields.
- Calculations: Jewel amount = metal weight × purchased rate per gram; Gross amount = Jewel amount + Stone amount + VA; Purchase price = Gross amount + GST − Discount.
- Calculated amount fields remain editable; changing upstream inputs refreshes dependent values.
- Current gold rate can be fetched from Goodreturns Bengaluru 22K/24K rates, with a source link and manual entry fallback.
- Current value is calculated as current gold rate × metal weight and remains editable.
- Jewellery entries open a detail dialog; jewellery photos and invoices open enlarged dialogs (PDF invoices are displayed in an embedded viewer).

## Assets rebalancing
- Split the existing-target and individual-asset guidance into separate persistent sub-dropdowns.
- Individual asset target rows now show current value, actual and target allocation, target value, suggested amount to invest or redirect, and consistent green/red/neutral colour coding.

## Compatibility
- Based on v3.37.0 and retains all post-v3.33 features, encrypted vault format, and Google Drive sync logic.
- Static asset query versions and service-worker cache bumped to v3.38.
