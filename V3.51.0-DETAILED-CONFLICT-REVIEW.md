# FinMate v3.51.0 — Detailed Conflict Review

## Purpose
Adds record-level detail to the existing read-only Google Drive comparison. It identifies records that are local-only, Drive-only, or have the same ID but different content. It can optionally export a JSON comparison report.

## Safety
- The comparison reads and decrypts the Drive vault but does not write to Drive.
- It does not merge, overwrite, or delete records.
- Record-only status does not prove which copy is newer.
- Exported reports may contain private financial information. Keep them secure and do not upload them publicly.
- This is not yet a shared cross-device baseline or record-level merge system.

## Staging test
1. Keep v3.50.0 and existing recovery backups untouched.
2. Deploy v3.51.0 to a staging copy / separate browser profile.
3. Confirm About reports 3.51.0.
4. Run Compare with Drive and confirm it lists record-level differences.
5. If prompted, test saving the JSON report and inspect that it contains status, collection, record ID and details.
6. Confirm comparison/export does not change the vault, Drive file, pending journal count, or media.
7. Confirm Retrieve remains blocked when local journal entries are pending.
8. Test with harmless records only and retain a recovery backup before any normal sync operation.

Source-level checks are not a substitute for testing against the user's actual Google Drive account.
