# FinMate v3.48.0 — Sync Foundation

## Included
- Keeps the v3.47.1 secure Google OAuth flow and separate IndexedDB `media` store.
- Adds a local IndexedDB `recovery` store and retains up to 10 encrypted core-vault recovery points on this browser/device.
- Saves a recovery point before Drive upload, Drive retrieval (which replaces local core data), and encrypted local-file import.
- Adds a Recovery points control in the Google Drive sync view. Restoring a point asks for the master password associated with that recovery point and verifies decryption before replacing the current local vault.
- Adds a sync-status summary showing last successful sync, status, and media items processed.
- After Drive upload, reads the encrypted core vault back from Drive and decrypts it before reporting the core upload as verified.
- On Drive retrieval, decrypts the downloaded core before changing local state; then retrieves referenced media and authenticates encrypted media before storing it locally.
- Keeps media uploads incremental by comparing the content hash recorded in Drive metadata, so unchanged media is skipped.

## Important scope boundary
This is the safety and incremental-media foundation, **not yet record-level two-way synchronization**. Core records are still synchronized as one encrypted vault snapshot. This version does not yet merge independent edits on two devices, maintain a complete record-level change journal/tombstones, or provide atomic manifest-based commits for the core and all media. Do not use simultaneous edits on two devices as if conflict-safe merging were already available. Continue to use one device as the editing source between syncs, and keep an independent encrypted export before major restores.
