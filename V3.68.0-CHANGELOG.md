# FinMate v3.68.0 — Incremental Media Retrieval, Password Visibility, Historical Gold Rates

## Changes
- Google Drive retrieval compares each encrypted attachment's SHA-256 metadata with the local encrypted media record and skips downloads when unchanged. Changed/missing local attachments are downloaded and authenticated; local-only media is not deleted during retrieval.
- Added an eye control to password/PIN inputs, including vault unlock and file/core-vault password prompts.
- Removed the loaded-script row from Settings → About.
- Moved Target allocation planner by Sector to the top of Sector-wise rebalancing ideas, before the recommendation rows.
- Expanded purchase-date gold-rate lookup: Goodreturns dated table/graph first, then the GoldPrice.org historical page as fallback. GoldPrice per-kilogram points are converted to per-gram; purity scales the 24K rate, and the field remains editable.
- Versioned app shell and cache names are updated to 3.68.0.

## Validation
- JavaScript syntax checked with `node --check app.js` and `node --check sw.js`.
- Manifest JSON parsed successfully.
- Static release checks verify version references, new script path, About row removal, password toggle hooks, incremental media hash skip, and planner placement.
- No live GitHub Pages, Google Drive account, or real browser end-to-end test was available in this build environment.
