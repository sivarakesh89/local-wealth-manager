# FinMate v3.14.0

- Added user-defined comma-separated tags to expense and income entry forms; tags are saved with each transaction and shown in the Transactions list.
- Added transaction filters for description search, category, tag, month, and year, while retaining date sorting.
- Dashboard income and expenses now reflect the selected month, defaulting to the current month, with a month picker.
- Updated app/cache version to 3.14.0.
