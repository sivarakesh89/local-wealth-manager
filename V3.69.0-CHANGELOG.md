# FinMate v3.69.0

## Category rename and historical update
- Added a Rename action to transaction category management.
- Renaming a category updates the category list and matching category values on historical transactions (expenses and income), recurring templates, and budgets across all profiles.
- New name validation prevents blank names and case-insensitive duplicates.
- Existing records are edited in place; their other fields and IDs are preserved.
- Updated application, script, manifest, and service-worker cache version references to 3.69.0.

## Validation
Static JavaScript syntax, manifest JSON, version-reference consistency, and ZIP integrity checks are performed for this package. Live browser, Android, and Google Drive synchronization testing is not implied.
