# FinMate v3.27.0

- Added mobile All Assets cards with quantity/average on the left and P/L %, P/L amount and LTP per unit on the right; desktop asset table remains unchanged.
- Fixed imported Sector mapping by preferring an exact `Sector` header.
- Removed Gold, Silver and Real Estate from Add Asset type choices.
- Added Wealth → Gold with investment/current value, gain/loss, weight, jewellery, inclusion/exclusion, photo, analytics and yearly summary.
- Added Wealth → Real Estate with property details, investment/current value, area, purchase date and deed/patta/chitta/other document storage.
- Fixed equity/debt/gold/silver allocation to derive from all applicable holdings instead of stock-only data.
- Pie legends now show both amount and percentage.
- Expense/Income pie charts can be filtered by month, defaulting to the current month.
