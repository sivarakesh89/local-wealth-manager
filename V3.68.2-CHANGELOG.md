# FinMate v3.68.2 — Jewellery UX, category management and safe stale-journal reconciliation

## Changes
- Jewellery list filters now use compact, transaction-style controls for type, tag and purchase year, plus free-text filters for jeweller, jewel name and notes.
- Jewellery detail popup decrypts and displays photo and image/PDF bill previews inline when attachments are stored separately in encrypted media storage. Clicking the preview continues to open the enlarged viewer.
- Removed the requested preset categories from available expense/income/recurring category choices. Added category management to add or delete categories. Deleting a category affects future choices only; historical transaction text is preserved.
- Drive retrieval now downloads/decrypts the remote vault before deciding whether a non-empty local change journal should block retrieval. If the local and remote record sets match (ignoring timestamps/sync metadata and the preset categories intentionally removed by this release), it acknowledges the stale journal and proceeds. If actual records differ, it keeps the guard and does not clear the journal.

## Data-safety notes
- No browser storage or IndexedDB is cleared.
- A recovery point is still created before replacing the local vault.
- Genuine local differences still block retrieval. This build has static checks only; Google Drive and browser/device end-to-end behavior must be verified by the user.
