# FinMate v3.36.0 — Restore mobile navigation drawer

## Fix
- Fixed a regression introduced by the touch-first responsive fallback: the mobile drawer was hidden with `display: none !important`, and the open state did not override that rule on devices reporting a desktop-sized viewport.
- Restored the hamburger button, slide-in navigation drawer, close button, overlay, and scrollable navigation on touch-first devices.
- Kept the compact mobile layout introduced in v3.35 and retained all v3.34+ app features, including persisted Transactions/Recurring/Budget disclosures and the separate Rebalancing section with Asset Allocation and Assets Rebalancing disclosures.
- No changes to vault encryption, IndexedDB schema, or Google Drive data format.
- Updated static asset versions and service-worker cache to v3.36.

## Validation
- JavaScript syntax checks and service-worker syntax checks passed.
- Static assertions verify touch-device drawer visibility rules, toggle/close actions, retained post-v3.33 navigation/features, and version/cache bump.
- ZIP integrity check passed. Physical Android Chrome testing and live Google Drive end-to-end testing were not available in this build environment.
