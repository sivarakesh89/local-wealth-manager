# FinMate v3.35.0 — Mobile layout after Drive retrieval

## Fix
- Added a touch-device responsive fallback for browsers that report a desktop-sized layout viewport (including Chrome when its Desktop site mode has affected the viewport).
- On touch-first devices, FinMate now uses the compact navigation, two-column summary cards, stacked content panels, and mobile form layout regardless of the reported viewport width.
- The layout is presentation-only and is not stored in or overwritten by the encrypted Google Drive vault.
- Kept the existing encrypted vault format, IndexedDB database/store, OAuth flow, and Drive sync logic unchanged.
- Bumped static asset query versions and service-worker cache to v3.35 so clients can receive the updated CSS.

## Validation
- JavaScript syntax checks and ZIP integrity checks passed.
- Static checks confirm the viewport metadata remains present and the new touch-layout fallback is included.
- Physical Android Chrome testing and live Google Drive end-to-end testing were not available in this build environment.
