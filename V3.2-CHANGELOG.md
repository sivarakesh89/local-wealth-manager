# FinMate v3.2.0

- Fixed imported transaction totals: imported Income/Expense values are now stored and aggregated using canonical transaction types, so Dashboard, Insights and Analytics include imported transactions correctly.
- Improved bank/credit-card statement parsing with Debit/Credit header variants and numeric parsing that preserves decimal values.
- Added a site-wide `oauth-config.js` bootstrap configuration so every new browser can discover the same secure Cloudflare OAuth Worker before the encrypted vault is retrieved. The Worker URL is public configuration; no client secret or financial data belongs in this file.
- Secure OAuth retrieval now uses the Worker flow on a new browser: site config → Worker `/start` → Google authorization → Worker `/callback` → one-time ticket → `/redeem` → encrypted Drive retrieval after vault unlock.
- Secure OAuth callback redemption can discover the Worker from the site-wide configuration even when localStorage is empty.
- Existing same-browser refresh-token flow remains supported.
