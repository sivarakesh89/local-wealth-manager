# FinMate v2.2.0 changelog

## Google Drive
- Improved Google OAuth diagnostics for popup-closed authorization failures.
- Sync → Advanced Google connection setup now shows the exact current FinMate origin and provides a Copy origin button.
- Error guidance now explains the two most common causes: Authorized JavaScript origin mismatch and missing Test user while the OAuth app is in Testing.
- The normal Drive flow continues to use the narrower `drive.file` scope and automatic FinMate folder creation.

## Branding and navigation
- FinMate sidebar branding is now vertical: large official gold-tree icon, FinMate name, tagline, then the complete menu.
- Mobile now uses the same full left-side navigation as laptop, opened/closed with a drawer button. The bottom-only navigation bar has been removed.
- Essentials, Reports and Sync are therefore available on mobile.

## Imports
- Fixed the file chooser event so contextual Import buttons actually open the Chrome file picker and process the selected file.
- Investment CSV import now treats Invested Amount as the fallback value. Average Cost is stored separately and is never treated as the current market price.
- PDF imports now attempt local text extraction with PDF.js and show a preview instead of only registering the PDF silently. FinMate deliberately does not auto-create transactions from arbitrary PDF layouts without a format-specific adapter.

## Market prices
- Refresh market prices now gives an explicit completion/failure message.
- Added support for common Yahoo symbols for Gold (`GC=F`), Silver (`SI=F`), Crypto (for example `BTC-USD`) and USD/INR conversion for INR-denominated physical metals.
- Mutual funds continue to use AMFI scheme codes.
- Updated P/L calculation uses Current Value minus Invested Amount.
- Real estate, vehicles and other manually valued assets remain manual unless a valid market symbol/source is provided.

## Themes
- Dark is the default theme for new vaults.
- Added Midnight, Aurora, Royal and Earth themes.
- Theme backgrounds now combine multiple accent colours instead of presenting a single-colour view.

## Security
- Lock Vault now explicitly indicates that enabled PIN/biometric methods can be used after locking.
- Biometric setup now checks WebAuthn client PRF capability where available and requests a platform authenticator with required user verification.
- PIN remains the practical fallback when the device/browser cannot provide PRF-backed local biometric key wrapping.

## Portfolio analytics
- Reworked pie charts as interactive SVG charts with colour indicators and hover titles showing category and percentage.
- Added stock allocation, stock sector, market-cap and asset-class charts.
- Added mutual-fund allocation, expense-category, income-category and bank-balance charts.
- Added portfolio P/L summary.

## Documentation
- README and all user-facing setup/update guides have been refreshed for v2.2.0.
