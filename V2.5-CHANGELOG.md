# FinMate v2.5.0

## Changes
- Reworked the vault unlock screen into an explicit method chooser: master password, 4-digit PIN, and device biometrics when enabled.
- PIN creation and confirmation now use masked password-style fields and numeric-only input.
- Added non-secret IndexedDB unlock flags so enabled PIN/biometric choices remain visible after locking; older records can be repaired after a password unlock.
- Investment entry now calculates Invested Amount from Average Cost × Quantity when both are present.
- Imported investment rows prefer Average Cost × Quantity for Invested Amount, while current value prefers LTP/current-price × Quantity. Imported LTP remains the imported/static value until a market-price refresh is run.
- Added stronger original-column/source-row preservation in the Assets section.
- Password-protected PDF import now uses a masked local password dialog and the PDF.js loading-task password callback.
- PDF text extraction now attempts generic Debit/Credit transaction parsing and adds detected rows to Transactions as Income or Expense.
- Added local background-image selection (up to 5 MB) instead of custom background-color selection. The image is stored inside the encrypted local vault.
- Added a Google Drive full-page compatibility fallback for GitHub Pages popup-return failures, plus improved OAuth state handling and diagnostics. The fallback is explicitly marked as legacy and is optional.
- Google Picker API key is now masked in the UI.
- Service-worker cache updated to v2.6.
