# FinMate v3.13.0

- Fixed account-switching sync behavior: verifies a saved Drive folder ID is accessible to the currently authorized Google account.
- If a saved folder belongs to another account or is inaccessible, FinMate clears that stale ID and discovers or creates a FinMate folder in the active account.
- Improved Drive folder/vault creation errors to include Google API error details when available.
- Bumped app and service-worker cache versions to 3.13.0.
