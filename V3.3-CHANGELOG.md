# FinMate v3.3.0

## Fixes
- Reworked imported transaction normalization so debit/credit columns take precedence and imported records retain debit, credit and raw amount values.
- Existing imported transactions are migrated/reclassified on unlock so Dashboard/Insights income and expense totals use the source transaction values.
- Added market metadata enrichment for imported stock/ETF holdings using the resolved ticker and configured price proxy/direct Yahoo Finance metadata when available. Fills sector and market-cap bucket (Large/Mid/Small) without overwriting explicit source values.
- Retrieve from Drive now refuses the Google GIS popup path when no secure OAuth Worker is configured, preventing the recurring popup_closed error. A public `oauth-config.js` Worker URL is required so a new browser can bootstrap the same Worker before it has a local vault.
- Service-worker cache bumped to v3.3.

## Important
For cross-browser Retrieve from Drive, set the existing Cloudflare Worker URL in `oauth-config.js` as `window.FINMATE_OAUTH_CONFIG.oauthBackend`. Do not place Google client secrets, API keys, refresh tokens, or financial data in that file.
