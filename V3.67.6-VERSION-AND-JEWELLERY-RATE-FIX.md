# FinMate v3.67.6 — Version and Jewellery Rate Fix

- Uses a unique `app-v3.67.6.js` script URL; `index.html` points directly to it.
- About now displays the actual loaded script filename alongside the app version to make stale deployments diagnosable.
- Gross weight is calculated as metal weight + stone weight, and the gross-weight field remains editable. Changing metal or stone weight recalculates gross weight; directly editing gross weight is allowed until either component weight changes.
- Purchased rate per gram attempts an exact-date lookup from the Goodreturns Bengaluru page for the selected purchase date and selected purity. The value remains editable. If Goodreturns does not expose that exact date in its page, the app clearly says so and does not silently substitute today's rate.
- Purity/date changes trigger a new purchase-rate lookup.

Validation performed: JavaScript syntax checks, service-worker syntax check, manifest JSON parse, and ZIP integrity. No live GitHub Pages/browser end-to-end test was possible here.
