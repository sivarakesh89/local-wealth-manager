# FinMate v3.31.0 — Change Log

- Removed the “Online · Local encrypted vault” status line from page headers.
- Updated the default app origin to `https://finmate.myfinapp.workers.dev` and OAuth Worker URL to `https://finmate-google-oauth.myfinapp.workers.dev`.
- Added Privacy Policy (`privacy.html`), Terms of Service (`terms.html`), and Help (`help.html`) pages, with clean-path directory copies.
- Added links to Privacy Policy, Terms, Help, and Contact developer under Settings → About FinMate.
- Pie charts now retain their title and show “No data available” when empty. Portfolio analytics is collapsible.
- Gold current rate and current value fields are editable; manually entered values are preserved when saving.
- Consolidated Gold/Real Estate photo/document actions into a single chooser that offers camera capture or file selection.
- Added month-specific overall and category expense budgets with live spend/limit progress in Transactions.
- Added multi-select investment linking to Goals, linked-value progress, and monthly/yearly contribution estimates to the target date.
