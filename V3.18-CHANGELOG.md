# FinMate v3.18.0

## Theme background correction
- Fixed a legacy custom solid-background override that could force the old dark-blue background regardless of the selected theme.
- The selected theme's `--bg` and `--panel2` colors now control the page background whenever **Background image mode → Use selected theme** is selected.
- Kept the existing **Use my background image** behavior unchanged. The stored image and its existing overlay/panel treatment remain intact when image mode is enabled.
- Bumped app and service-worker cache versions to v3.18.0.
