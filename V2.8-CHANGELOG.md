# FinMate v2.8.0

## Google Drive OAuth callback fix
- Corrected the GitHub Pages origin for the secure OAuth Worker to `https://sivarakesh89.github.io`.
- The Worker now supports an `APP_ORIGIN` Worker variable and defaults to the corrected origin.
- The Worker validates `return_to` against the configured application origin, preventing redirects to unrelated hosts.
- `/health` now reports the configured application origin and callback URI for easier diagnostics.
- Updated Worker and Google OAuth setup documentation with the corrected origin.

This release does not change the encrypted-vault format or local financial data model.
