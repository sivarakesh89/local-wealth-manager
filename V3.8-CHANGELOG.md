# FinMate v3.8.0

## Google Drive upload/retrieve safety
- Replaced ambiguous **Sync now** wording with explicit **Upload to Drive** and **Retrieve from Drive** actions.
- The app now clearly treats Drive as the encrypted cross-device transport: upload saves the current device vault; retrieve replaces the current device data with the Drive vault.
- Added a protection against accidentally uploading a new/empty local vault over an existing Drive vault. FinMate asks for explicit confirmation before such an overwrite.
- Retrieving onto a device that already has meaningful local data also asks for confirmation before replacement.
- The normal cross-device flow is now: **Device A → Upload to Drive → Device B → Connect → Retrieve from Drive → unlock with the same master password**.

## Password-protected Excel
- Kept the password prompt for encrypted spreadsheets.
- Improved the error message so unsupported Excel encryption is distinguished from an incorrect password and gives a privacy-preserving local workaround: open in Excel/LibreOffice and save/export an unencrypted XLSX/CSV.
- FinMate does not upload the spreadsheet to decrypt it.
