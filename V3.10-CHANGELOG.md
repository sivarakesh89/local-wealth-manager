# FinMate v3.10.0

- Removed the Refresh market prices buttons from Dashboard and Wealth. Existing price-refresh functionality remains available through its other supported workflow.
- Added an inline Type selector to each holding, alongside the existing Sector, Market Cap, and Asset Class selectors.
- Moved Reports out of the main navigation and added a Reports & exports shortcut within Settings.
- Version and vault namespace updated to 3.10.0.

Note: Sector and market-cap enrichment remains dependent on reliable metadata/provider matches; unknown values are intentionally left Not set rather than guessed.
