# FinMate v3.1.0

## Fixes
- Fixed mobile Transactions layout: removed forced minimum table width, disabled horizontal scrolling, and enabled wrapping for long descriptions and action buttons.
- Fixed Retrieve from Drive to prefer the configured secure OAuth backend instead of falling back to the Google Identity Services popup. If a saved secure refresh token is unavailable/expired, FinMate now starts the secure full-page OAuth flow directly.
- Kept the existing encrypted Google Drive vault format and Worker architecture unchanged.
