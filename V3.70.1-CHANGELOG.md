# FinMate v3.70.1 — Silver calculations and historical-rate worker fix

## Fixes
- Historical gold rate calculator now creates the DuckDB CDN worker via a Blob bootstrap, instead of constructing a Worker directly from a cross-origin URL. This addresses the reported `Failed to construct 'Worker'` origin error. Network access and CDN availability are still required.
- Silver Delete action is handled before the generic `delete-*` dispatcher, fixing the route that previously sent the action to the wrong deletion handler.
- Silver form values now calculate live: weight × purchased rate ↔ purchase price, and weight × current silver rate ↔ current value. When a rate is blank but the paired amount and weight exist, the rate is derived.
- Existing Silver investment records and other vault data are not cleared or migrated destructively.

## Validation status
JavaScript syntax checks, version-reference checks, and ZIP integrity checks are performed for this patch. No live browser, Android, CDN or Google Drive end-to-end test has been performed.
