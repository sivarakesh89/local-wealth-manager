# FinMate v2.4.0

## Navigation
- Added a dedicated scrollbar inside the left navigation pane so all sections remain reachable on desktop and mobile drawer layouts.

## Imports
- Preserves original imported column headings and raw source rows for CSV/XLSX imports.
- Wealth imports now prefer an explicit Current Value/Market Value column; otherwise they initialize value from Invested Amount, never Average Cost alone.
- Imported rows retain source headings and raw row data for audit/reference.
- Password-protected PDFs now prompt for the PDF password during local PDF.js parsing.

## Market prices
- Refresh runs market-linked holdings in parallel with per-request timeouts.
- The result modal shows only successfully updated holdings, with current price, current value and profit/loss.
- Wealth asset table now includes Current Price and last-updated time.
- Gold/silver unit conversion is corrected for grams vs ounces.
- Manual assets such as real estate/vehicles/PPF/EPF still require a manual valuation or a dedicated market data source.

## Security
- PIN is now exactly 4 digits.
- When a PIN is enabled, the vault lock screen presents a 4-digit PIN field first, with password fallback.

## Analytics
- Added dedicated portfolio analytics charts for stock allocation, sector, market-cap, equity/debt/gold/silver, mutual funds, expenses, income and bank balances in the Wealth section.

## Themes
- Dark remains the default.
- Added Sapphire, Emerald, Royal Sunset and Sand & Ocean themes with multi-tone/selective backgrounds.

## Google Drive
- Improved Google Identity Services diagnostics and explicit consent handling.
- Error messages now surface the current FinMate origin and likely popup/origin/test-user causes.
