# FinMate v3.12.0

- Expanded Google Drive authorization to include read-only access so retrieval can locate vault files uploaded manually or shared into the authorized account, in addition to app-managed file operations.
- Updated the secure OAuth Worker scope list to match the app. Existing users may need to authorize again and grant the added permission.
- Clarified that passwords and PINs are not recoverable by FinMate. Users who know the master password can unlock and configure a replacement PIN in Settings.
