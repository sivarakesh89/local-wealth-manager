# FinMate v3.16.0

- Tightened Transactions table padding and column widths to make the list more compact.
- Kept Edit and Delete actions available on each transaction row.
- Added column-heading dropdown filtering for transaction type and minimum/maximum amount fields.
- Simplified date filtering to a single month picker (month and year together); removed separate year input.
- Moved Sort by beside Delete All in the Transactions panel heading. Sorting supports newest/oldest date and amount high-to-low/low-to-high.
