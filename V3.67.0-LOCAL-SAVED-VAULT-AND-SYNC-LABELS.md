# FinMate v3.67.0 — Local Saved Vault and Sync Labels

## Changes
- Google Drive buttons are now **Upload to drive** and **Retrieve from drive**.
- Local file buttons are now **Save FinMate vault locally** and **Retrieve from local saved vault**.
- Local save creates one JSON bundle with the encrypted core vault and all media attachments referenced by the current vault. Each attachment is validated before the bundle is offered for saving.
- Local restore validates the core using the master password and verifies each referenced encrypted attachment before saving a recovery point and applying the restore. Media is restored into local IndexedDB; nothing is uploaded to Drive.
- Legacy encrypted core-only vault JSON remains supported for compatibility, but contains no media payload.
- The duplicate standalone **Export viewer as HTML** button was removed; the action remains inside **Conflict apply audit viewer**.
- Privacy policy, terms and help pages now describe these behaviors.

## Safety notes
Keep the saved vault file private and preserve the original. Restore replaces the current vault after verification. Large bundles can require substantial browser memory. This release received static syntax/structure checks only; test a save-and-restore cycle on a separate browser profile before relying on it as a backup.
