# FinMate v3.66.5 — Stable Record Journal

## Purpose

This release targets the v3.66.4 failures where pending changes jumped to 154 on unlock and stayed around 54–55 after routine edits and reloads.

## Changes

- Assigns missing record IDs during migration/unlock, before ordinary persistence and journal diffing. This prevents legacy records without IDs from being assigned fresh IDs during each change comparison.
- Uses a stable, sorted-key JSON representation when comparing records, preventing property insertion order from being treated as a real update.
- Compares the global `imports` collection against the prior vault's global `imports` collection rather than a profile property that is not part of the profile schema.
- Retains the serialized encrypted journal-write queue, retrieval suppression, and verified upload acknowledgement behavior.

## Safety notes

- This release does not clear the existing pending journal on unlock. Existing entries may include real edits; they should only be acknowledged by the existing verified upload/retrieval flows.
- Do not clear browser storage or delete IndexedDB records to troubleshoot this issue.
- Keep a copy of the currently deployed ZIP and a current encrypted vault backup.
- This release has passed static JavaScript syntax, manifest JSON, and ZIP integrity checks. It has not been tested against the user's live Google Drive account.

## Expected regression results

1. Unlock without editing does not increase the pending count.
2. A single added record produces one effective pending record.
3. Editing that same record keeps the effective count at one.
4. Successful verified upload clears the journal to zero.
5. Reload/unlock does not recreate false entries.
6. Retrieve after reload, Google authorization, and master-password unlock finishes with zero pending changes.
7. Creating and deleting the same unsynced record returns to zero for that record.
8. A further reload after verified sync remains at zero.

The count is the number of effective pending journal entries, not a count of individual field edits.
