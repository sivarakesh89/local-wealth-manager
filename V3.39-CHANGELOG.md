# FinMate v3.39.0

## Changes
- Drive vault discovery now orders same-named files by latest modified time, bypasses browser cache for vault listing/downloads, and verifies the just-uploaded remote payload timestamp when available. This targets stale/duplicate vault selection during laptop-to-mobile retrieval.
- Gold jewellery is split into saved-state dropdowns: “Your jewellery” (Include in my investment = Yes) and “Other jewellery” (No). Both can be sorted newest/oldest by purchase date.
- Added a Gold page action to fetch Goodreturns Bengaluru 22K/24K rates once and update the current gold rate and current value for every jewellery record.
- Real-estate cards open a full property detail popup; property photos, deed, patta, chitta and other saved documents open in image/PDF popups.
- Existing encrypted vault format and all post-v3.33 features are retained.

## Validation
JavaScript syntax, static feature assertions, and ZIP integrity checks are run before release. Live Google Drive and Goodreturns behavior depends on OAuth permissions, source availability, and proxy/CORS configuration; it must be verified in the deployed environment.
