# FinMate v3.9.0

- Upload and Retrieve now start secure OAuth authorization automatically when no access token is available.
- OAuth callback remembers both upload and retrieve intent and resumes the requested operation after vault unlock.
- Removed the separate “Connect with secure OAuth backend” action from the primary Sync controls; the backend remains configured automatically and advanced configuration is available in Settings.
- Improved sync error messages so empty/unknown errors show a useful fallback instead of a blank popup.
