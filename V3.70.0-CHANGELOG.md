# FinMate v3.70.0 — Silver investments and historical gold-rate integration

- Added a Silver page between Gold and Real Estate with separate encrypted-vault records, yearly summary, gain/loss, add/edit/delete and categories Coins, Bars, Ornaments and Others.
- Added Gold bonds to jewellery categories.
- Added a small Auto fetch button for Purchased rate per gram. New entries no longer automatically trigger the previous purchase-rate lookup; users can request a historical reference rate explicitly.
- Integrated the supplied `gold-rate-calculator.js` and scoped stylesheet. Auto fetch uses the package's historical India gold dataset and requires internet access; it is a reference rate, not a jeweller quote.
- Gold yearly summary includes gain/loss and return percentage.
- Updated app/script/manifest/service-worker cache version references to 3.70.0.

## Data source and licensing note
The attached calculator package uses a community-maintained historical dataset whose supplied README warns about non-commercial/personal research restrictions. Check the dataset license before public or commercial distribution.

## Validation
Static JavaScript syntax, manifest JSON, version-reference and ZIP integrity checks are performed for this release. No live browser, Android, market-data or Google Drive end-to-end test is claimed.
