# FinMate v3.47.1 — Secure OAuth authorization resume fix

## Fix
When Backup Now / Upload core + media is clicked without a valid secure OAuth refresh token, FinMate now starts the configured secure OAuth Worker flow and records whether the user intended to push or pull. On return, the existing callback path resumes the requested operation.

## Important
- This does not bypass Google authorization or create a token locally. The user must complete Google sign-in and consent.
- It does not change the OAuth Worker or its secrets.
- It does not upload data until authorization succeeds.
- Keep v3.46.3 and existing backups unchanged until a successful upload and restore are verified.

## Validation
`node --check app.js` and `node --check sw.js` passed. This patch has not been end-to-end tested with the user's Google account or live Worker.
