# FinMate v3.4.0

- Reworked PDF transaction extraction to use PDF text positions/column alignment when available, with a text fallback.
- Preserves more extracted PDF positional data for diagnostics/recovery.
- Google Drive new-browser retrieval now uses the configured OAuth Worker and can bootstrap the encrypted vault before local unlock.
- Drive sync payload now includes the password-wrapped data-key record required to unlock the vault on a new browser. The wrapper is encrypted with the master password; plaintext financial data is not sent to the Worker.
- Configured the supplied FinMate OAuth Worker URL in the public site configuration.
- Expanded holdings metadata enrichment to up to 250 unique holdings and broader listed-equity/ETF matching.
- New-browser retrieval now stores/downloads the encrypted password-wrapped data key before unlock; no plaintext vault is exposed to the OAuth Worker.
- Holdings enrichment now considers existing ticker/symbol values, Name/Instrument, and ISIN for metadata rather than only rows missing a ticker.
