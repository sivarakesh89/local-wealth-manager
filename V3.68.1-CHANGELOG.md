# FinMate v3.68.1 — Jewellery filters and gold-rate workbook

## Changes
- Added Jewellery list filters for jewellery type, tag, and purchase year; filters apply to both included and other jewellery.
- Preserved newest-first and oldest-first sorting and added sorting by metal weight, purchase amount, purity, and earnings (gain/loss), each in ascending and descending order.
- Added an Import gold-rate Excel control in the Gold section.
- Imported gold-rate rows are stored inside the encrypted FinMate vault settings and are used before attempting web lookup for the entered purchase date and purity.
- Exact dated workbook rows take precedence. Annual-reference rows are a clearly labelled year-level fallback, not an exact historical daily quote.
- Updated application, script, manifest, and service-worker cache references to v3.68.1. About continues to omit the loaded-script row.

## Data source and limitations
The accompanying workbook contains separate year sheets for 1990–2026. Publicly accessible sources reviewed did not provide a complete verified daily Bengaluru rate series for every date back to 1990. Therefore, 1990–2025 entries are indicative annual India reference prices converted from ₹/10g to ₹/g; 18K is derived as 75% of 24K. The 2026 sheet contains a current Bengaluru quote for 23 October 2026 and a clearly marked provisional year fallback. Do not treat annual reference rows as exact purchase-date valuations; use jewellery invoices or verified daily quotes where precision matters.

Sources:
- CoinSwitch historical annual reference prices: https://coinswitch.co/gold-rates/gold-rate-today-in-india
- Groww Bangalore gold rate, checked 23 October 2026: https://groww.in/gold-rates/gold-rate-today-in-bangalore
