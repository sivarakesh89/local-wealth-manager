# FinMate v3.67.3 — About Version / Cache Update Fix

## Fix
- Application version constant is `3.67.3`, which is the value displayed in Settings → About FinMate.
- Service-worker cache name bumped to v3.67.3 so prior app-shell caches are retired on activation.
- Service-worker registration disables HTTP-cache reuse for worker updates and explicitly calls `registration.update()`.
- The service worker now uses network-first requests for the app shell (`index.html`, `app.js`, CSS, manifest and worker), with cached fallback for offline use. This prevents an old cached `app.js` from keeping the About panel on v3.67.1 after deployment.

## Validation
- `node --check app.js` and `node --check sw.js`
- `manifest.webmanifest` JSON parse
- ZIP integrity check

No live GitHub Pages/browser test was run in this build environment.
