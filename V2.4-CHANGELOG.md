# FinMate v2.4.0 changelog

## Google Drive authentication
- Added GIS load-wait handling so the app does not race Google Identity Services.
- Added a local Google Drive diagnostics panel.
- Improved popup error diagnostics for `popup_closed` and popup-open failures.
- Normal Drive access still uses the narrow `drive.file` scope; only the encrypted vault is synced.

## Investment imports and assets
- Preserves original imported headings and complete source rows in the Assets list.
- Added a dedicated “Imported holdings — original columns” table with exact source columns plus computed Current Value, Invested Amount and P/L.
- Main asset list now includes quantity/units, average cost, invested amount, current price/value, ISIN, sector, market cap and asset class.
- Current Value priority is explicit Current Value/Market Value/Valuation, otherwise Current Price × Quantity/Units, otherwise zero. Average Cost is never used as Current Value.
- P/L is always Current Value − Invested Amount.

## PDF import
- Fixed password-protected PDF handling by using PDF.js `loadingTask.onPassword` on the main thread instead of passing a function through the worker message.
- Passwords are requested locally and are not stored.

## Appearance
- Added a custom background color picker. Themes continue to control panels, accents and text.
- Dark remains the default theme.

## Unlock
- PIN unlock is explicitly 4 digits.
- Unlock screen now shows all enabled methods directly instead of hiding the master-password option in a collapsed fallback.
- PIN/biometric wrappers are repaired into the local vault record after password unlock when an older record stored them only inside encrypted state.
