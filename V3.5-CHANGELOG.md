# FinMate v3.5.0

- Reworked PDF positioned-column transaction extraction to avoid treating balance values as debit/credit amounts.
- Preserves extraction mode in imported PDF source rows for diagnostics.
- Fixed cross-browser Google Drive retrieval bootstrap: secure OAuth Worker is checked before requiring a local Google Client ID, and refresh tokens can be used from session storage.
- Added public Worker configuration already set to the user's supplied FinMate OAuth Worker URL.
- Added "Identify / enrich holdings" action for existing holdings.
- Improved holding metadata enrichment using Name/Investment/Instrument, ISIN, ticker and external market metadata when available.
- Added global horizontal-overflow protection and wrapping across all sections, including Wealth.
