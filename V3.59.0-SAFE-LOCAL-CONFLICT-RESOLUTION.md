# FinMate v3.59.0 — Safe Local Conflict Resolution

## What changed
- Three-way review worksheets now include local and Drive SHA-256 fingerprints for each reviewed record.
- Sync page adds **Apply approved local decisions (XLSX)**.
- Import requires the FinMate worksheet format, valid decisions, matching baseline/Drive vault IDs, zero pending journal entries, and exact current local/Drive record hashes.
- A local encrypted recovery point is saved before applying any `KEEP_DRIVE` decisions.
- `KEEP_DRIVE` copies the current Drive record into the selected local profile, or removes the local record when Drive is missing it. `KEEP_LOCAL` is a no-op. `KEEP_DELETION_UNRESOLVED` is accepted only as a no-op for records absent on both sides. `UNRESOLVED`, stale hashes, or invalid choices stop the entire operation.
- This feature does not upload to Drive, update the shared baseline, or write to the media store.

## Important limits
- Always generate a fresh worksheet with v3.59.0; worksheets from earlier versions do not contain the required fingerprints.
- This is local-only conflict application, not a bidirectional merge engine. Resolve a small batch on a disposable staging profile first.
- The recovery point stores the encrypted vault record. It does not copy the separate IndexedDB media store; this feature does not modify media.
- After applying, inspect records and attachments before any later manual upload.
- JavaScript syntax and package checks are not browser/Drive end-to-end tests.

## Staging test plan
1. Deploy v3.59.0 to a disposable browser profile and confirm About shows `3.59.0`.
2. Create controlled changes on local and Drive staging copies, then publish a matching shared baseline and run three-way review.
3. Confirm workbook contains Summary, Decisions, Instructions and the two SHA-256 review columns; decisions begin as `UNRESOLVED`.
4. Attempt apply with an unresolved row; verify it stops and makes no record changes.
5. Change one safe row to `KEEP_LOCAL` and another to `KEEP_DRIVE`; apply and verify only the approved Drive-side record is copied locally.
6. Verify a local recovery point exists and pending journal entries reflect local changes.
7. Confirm Google Drive vault, shared baseline and media entries are unchanged by the apply operation.
8. Modify a local record after exporting a worksheet and try applying it; verify stale-hash rejection and no changes.
9. Try an old worksheet without hashes; verify rejection.
10. Manually review local records and media before any upload.
