# FinMate v3.37.0

## Mobile layout regression fix
- Added device/viewport-based mobile layout detection applied before vault unlock and re-evaluated on resize/orientation changes.
- Mobile presentation is controlled by a document-level class and is independent of synced financial settings or encrypted vault contents.
- Added explicit mobile styling for the navigation drawer, bottom navigation, cards, asset lists, forms, transactions, and rebalancing disclosures when Chrome reports a desktop-sized layout viewport.
- Preserved v3.34+ features, local encrypted vault format, and Google Drive sync logic.
- Bumped asset query versions and service-worker cache to v3.37.

## Validation
- JavaScript syntax and ZIP integrity checks performed on the release package.
- Real-device browser/PWA testing is still required.
