# FinMate v3.33.0

## Changes
- Transactions and budget/recurring content is grouped under a collapsible Transactions & budgets disclosure. The current month is selected by default in the transaction date filter; Clear all filters is available.
- P/L values now show their percentage alongside the amount in holdings, gold, real estate, portfolio analytics and imported holdings.
- Mobile stock, mutual fund and bond cards open the existing Add/Edit Asset dialog when tapped; the dialog provides a delete action while preserving the compact card layout.
- Income and expense forms share the same category list and custom-category workflow.
- Holdings imports read target-allocation columns (including percentage-formatted values) into each asset.
- Expense and income entries include Notes; transaction imports map the Notes column and transaction descriptions show notes after a hyphen.
- Privacy Policy, Terms of Service and Help are accessible before vault creation and on the unlock screen.
- Sync page shows Google Drive connection status instead of a separate Connect Google Drive button; Upload and Retrieve remain the entry points for connection/sign-in.
- Insights rebalancing includes editable target allocation percentages by asset class and comparative guidance based on recorded portfolio values.
- Essentials monthly income, expenses and investment-category savings can auto-calculate from current-month transactions, with manual overrides available.
- Updated app and service-worker cache versions.

## Validation
JavaScript syntax and ZIP integrity checks are run for this package. Live OAuth/Drive, browser interaction and physical-device testing are not implied by these checks.
