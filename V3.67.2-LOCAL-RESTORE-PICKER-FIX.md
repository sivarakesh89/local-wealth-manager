# FinMate v3.67.2 — Local Restore Picker Fix

- Fixed local restore flow so selecting the core vault is followed by an explicit in-app step and a user-clicked button to open the multi-file media picker. This avoids browsers silently blocking the second picker.

- Local restore verifies the encrypted core and all referenced media before replacing the current vault, and creates a recovery point first.
- Updated app/cache version to 3.67.2 and revised user guidance.

Validation: JavaScript syntax, manifest JSON, ZIP integrity, and static assertions. No live browser or Google Drive end-to-end test was run.
