# FinMate v3.34.0

## Changes
- Split Transactions, Recurring and Budgets into three independent disclosure sections.
- Persist each disclosure's expanded/collapsed preference in browser local storage so filter changes and page re-renders do not collapse open sections; preferences survive reloads on the same browser.
- Added a dedicated Rebalancing subsection under Insights navigation.
- Split Rebalancing into independent Asset Allocation and Assets Rebalancing dropdowns. Each section includes its corresponding pie chart; the assets section also includes the existing target-allocation planner and guidance.
- Updated app asset query versions and service-worker cache to v3.34.

## Validation
- JavaScript syntax checked with `node --check app.js` and `node --check sw.js`.
- ZIP integrity checked after packaging.
- No live Google Drive/OAuth, browser UI, or physical-device end-to-end tests are claimed.
