# FinMate v3.55.0 — Shared Baseline Review

## Purpose
Adds a read-only **Review shared baseline** action. It downloads and decrypts the separately encrypted `FinMate-shared-baseline.enc.json`, then compares the current local profile with the stored fingerprints. It reports local records added since baseline, records whose contents differ, records present in the baseline but missing locally, and unchanged records.

## Safety and limitations
- Does not upload, overwrite, or delete the vault or baseline.
- Does not merge records or automatically resolve conflicts.
- A record missing locally is not proof of an intentional deletion.
- The baseline is a historical reference, not a current snapshot of the remote vault. This feature compares the local state with the shared baseline; it does not independently compare the current remote vault with the baseline.
- A JSON report may contain private record IDs and labels; keep it secure.

## Staging test
1. Keep v3.54.0 and recovery backups unchanged.
2. Deploy v3.55.0 to a staging profile and verify About shows 3.55.0.
3. Open Settings → Google Drive → Review shared baseline.
4. Confirm authorization recovery works if needed and the report counts match harmless test changes made after baseline publication.
5. Save the optional drift report and inspect its summary and details.
6. Confirm local records, Drive vault, shared baseline file, media and pending-change count are unchanged.
7. Confirm Retrieve remains blocked when local journal entries are pending.

Source-level syntax checks and ZIP integrity checks do not replace live Google Drive testing.
