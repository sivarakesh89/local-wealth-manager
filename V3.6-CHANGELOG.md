# FinMate v3.7.0

- PDF extraction removed from the normal import workflow; CSV/XLS/XLSX is the supported statement path.
- Retrieve from Drive always uses the configured FinMate secure OAuth Worker on a new browser and no longer falls back to GIS popup for retrieval.
- Worker URL is embedded as public configuration: https://finmate-google-oauth.ssrakesh5.workers.dev
- Wealth import renamed to generic “Import investment data”.
- Removed Identify / enrich holdings and Recover PDF imports buttons.
- All Assets now provides inline dropdowns for Sector, Market Cap and Asset Class with immediate persistence.
- Imported source columns are collapsed by default and expandable when needed.
- Import enrichment runs after the import completes instead of blocking the preview/save path.
- Monetary formatting uses up to 3 decimal places.
- Account selector added to Add/Edit Expense and Income using existing bank accounts.
- Global horizontal overflow protection and wrapped table content applied across sections.
